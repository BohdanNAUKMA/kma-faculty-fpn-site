# kma-faculty-fpn-site


## 1. Вибір факультету
* **Обраний факультет:** Факультет природничих наук НаУКМА (ФПрН).
* **Обґрунтування:** На відміну від ФІ чи ФПвН, Факультет природничих наук не має власного окремого вебресурсу і представлений лише базовою інформаційною сторінкою на головному порталі `ukma.edu.ua`. Факультет має збалансовану структуру (4 кафедри, природничі спеціальності, наукові лабораторії), що дозволило наповнити сайт реальними відкритими даними.

## 2. Кількість місць: опрацювання значення «до 4» (Пункт 3)
* **Рішення:** Поле `seats` конвертовано у `PositiveIntegerField`. Для значення «до 4» збережено числове значення `4` як верхню межу квоти (максимальну місткість програми, яку пропонує партнерський університет).
* **Пояснення:** У реляційних базах для числових полів потрібні скалярні значення для коректного сортування та агрегації. Для збереження гнучких умов у майбутньому можна додати прапорець `is_quota_approximate`, проте збереження максимальної кількості місць є найбільш інформативним для студента. При конвертації прийменник «до» відкидається.

## 3. Статус прийому заявок (Пункт 4)
* **Питання:** Чи варто зберігати статус прийому в базі окремим полем? Чому?
* **Відповідь:** Зберігати статус у базі окремим полем **не варто**.
* **Чому:** Статус «Прийом триває» / «Прийом завершено» є похідним значенням (computed property), яке динамічно залежить від поточної дати (`deadline >= today`). Якщо зберігати його у базі (наприклад, через `BooleanField`), дані застаріють на наступний день після дедлайну, якщо не налаштувати щоденний cron-скрипт чи фонову задачу Celery для оновлення. Розрахунок на льоту через `@property is_active` у моделі гарантує актуальність без додаткових запитів чи фонового навантаження.

## 4. Аналіз зворотності міграцій та втрати даних (Пункт 5)
Усі міграції застосунку підтримують повний прохід в обидва боки (`migrate faculty zero` та `migrate`).

Міграції, які відкочуються з частковою втратою даних:
1. **`0005_split_university_and_country`**: при зворотному злитті країни та університету назви поєднуються назад через кому/дужки, проте початкові довільні розділювачі деканату частково уніфікуються.
2. **`0006_clean_seats_data` та `0007_convert_seats_to_integer`**: при прямій міграції текстові маркери («до 4», «2 місця», «1 місце») очищуються до цифр. При зворотному відкаті в текстове поле повертається лише строкове представлення числа (`'4'`, `'2'`, `'1'`), а первинні слова («до», «місця») безповоротно втрачаються.
